이미지 / 영상 보관 폴더
========================

[히어로 배경 영상] — index.html 히어로가 아래 파일을 자동으로 사용합니다.
  hero.mp4         권장: 1920x1080, 8~15초 루프, 무음, H.264, 3~6MB 이하로 압축
  hero.webm        선택: VP9/AV1 (더 가벼움, 우선 적용됨)
  hero-poster.jpg  영상 로딩 전/실패 시 보여줄 첫 프레임 이미지 (1920x1080)
  → 강남 야경, 라운지 인테리어, 조명/네온 무드 영상을 권장합니다.
  → 파일만 이 폴더에 넣으면 추가 코드 수정 없이 바로 적용됩니다.
  → 영상이 없으면 다크 그라디언트 + 골드 글로우 배경으로 자동 폴백됩니다.

[기타]

  객실/시설 사진   WebP 포맷 + loading="lazy" 권장
