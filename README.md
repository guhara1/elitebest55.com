# 강남 가라오케 엘리트 — elitebest55.com

선릉역 · 대치동 프리미엄 가라오케 라운지 마케팅 랜딩 페이지.
순수 정적(HTML/CSS/JS) 사이트로, 별도 빌드 과정 없이 바로 배포할 수 있습니다.

## 구조

```
.
├── index.html        # 단일 랜딩 페이지 (GNB · 히어로 · 라인업 · 객실 · 메뉴 · 후기 · 위치 · 예약 · 푸터)
├── css/style.css     # 다크 럭셔리 테마, 반응형/모바일 최적화
├── js/main.js        # 모바일 메뉴, 스크롤 효과, 등장 애니메이션, 예약 폼 검증
├── robots.txt
├── sitemap.xml
└── assets/           # 이미지(히어로/객실 사진 등) 보관 위치
```

## 페이지 구성 (스크롤 순서)

1. **상단 메뉴 (GNB)** — 로고 / 메인 메뉴(라인업·객실&시스템·위치·이용안내) + 드롭다운 / 24시 콜센터·실시간 예약 버튼. 스크롤 시 상단 고정(Sticky).
2. **히어로 배너** — 메인 카피 + "지금 전화해서 실시간 예약 확인하기" CTA.
3. **실시간 라인업 안내** — 전화 / 카카오톡 / 폼 상담 경로 안내.
4. **객실 & 시스템** — 스탠다드 / 프리미엄 / VIP 플래티넘 룸 + 시설 특징(음향·조명·KY/금영).
5. **주류 & 패키지 안내** — 패키지 카드 (가격은 전화 문의).
6. **고객 후기**
7. **위치 & 오시는 길** — 지도 영역(카카오맵/네이버맵 삽입 자리) + 주소/전화/운영시간.
8. **예약 / 상담 신청 폼** — 이름·연락처·시간·인원·특이사항 + 개인정보 동의 체크박스.
9. **푸터** — 사업자 정보 + 법적 고지(촬영 금지, 만 19세 미만 출입 금지) + 연락 버튼.
10. **모바일 하단 고정 액션바** — 전화/예약 버튼 (모바일에서 항상 노출).

## 배포 / 커스터마이징 체크리스트

- [ ] 전화번호 `000-0000-0000` 를 실제 번호로 일괄 변경 (`tel:` 링크 포함)
- [ ] 주소·사업자등록번호·대표자명 등 푸터 정보 입력
- [ ] 지도 영역(`.location__map`)에 카카오맵/네이버맵 임베드 코드 삽입
- [ ] `assets/` 에 히어로/객실 이미지 추가 후 연결 (WebP 권장 + `loading="lazy"`)
- [ ] 카카오톡 채널 / 네이버 톡톡 링크를 예약·상담 버튼에 연결
- [ ] 예약 폼 전송 대상(서버 API 또는 메신저 연동) 구현 — 현재는 프런트 검증만 동작
- [ ] OG 이미지(`assets/og-cover.jpg`) 추가

## 적용된 기술 포인트

- **모바일 최적화**: 상단 GNB Sticky 고정 + 모바일 전용 하단 고정 액션바.
- **반응형**: 980 / 820 / 480px 브레이크포인트.
- **성능**: CSS/JS 분리, `defer` 스크립트, 폰트 preconnect. 이미지 추가 시 WebP + lazy loading 권장.
- **SEO**: 메타 태그, Open Graph, `robots.txt`, `sitemap.xml`, JSON-LD(LocalBusiness) 구조화 데이터.
- **접근성**: 시맨틱 마크업, ARIA 속성, 키보드 포커스 드롭다운, `prefers-reduced-motion` 대응.
